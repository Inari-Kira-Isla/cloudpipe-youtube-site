隱私權政策（Privacy Policy）

最後更新：2026-10-02

1. 這個應用程式是什麼

CloudPipe-YouTube（以下稱「本應用程式」）是 Joe Cheok 個人自行使用的內部工具，只供營運者管理自己擁有的 YouTube 頻道，不對公眾開放，也沒有其他使用者。

2. 我們存取哪些資料

經營運者本人授權後，本應用程式透過 Google OAuth 與 YouTube API 存取營運者自己 YouTube 頻道的下列資料：

  • 上傳影片，及更新自己影片的標題、說明、標籤、縮圖與公開狀態；
  • 讀取自己頻道與影片的基本資料及觀看數據（例如觀看次數、觀看時間）。

本應用程式不會存取其他人的資料。

3. 資料如何使用與保存

  • 資料只用於上述頻道管理與數據檢視用途。
  • 授權憑證（OAuth token）僅儲存在營運者自己的電腦上，不會上傳到任何第三方伺服器。
  • 讀取到的頻道數據只儲存在營運者自己的電腦上。

4. 資料分享

我們不會出售、出租、交易或與任何第三方分享 Google 使用者資料，也不會將其用於廣告或投放個人化廣告。

5. Google API 服務使用者資料政策

本應用程式使用及轉移從 Google API 取得的資訊時，會遵守 Google API 服務使用者資料政策，包括其中的「有限使用」（Limited Use）規定。

6. 撤銷授權與刪除資料

營運者可隨時前往 Google 帳戶的第三方存取權管理頁面撤銷本應用程式的存取權，並可刪除電腦上儲存的授權憑證與數據檔案。

7. 聯絡方式

如有任何疑問，請聯絡：inariglobal@gmail.com

Privacy Policy (English summary)

It is not offered to the public. Access is granted only by the operator through Google OAuth. OAuth tokens and channel data are stored only on the operator's own computer. We do not sell, share, or transfer Google user data to third parties and do not use it for advertising. Use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.
